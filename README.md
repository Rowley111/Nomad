# Nomad Mobile — CRM для скупки и перепродажи техники

React + Vite. Рабочий MVP без сервера. Интерфейс на русском, валюта KZT.

## Возможности

- Каталог устройств: модель, ОЗУ, накопитель, состояние, АКБ, коробка, примечания.
- Создание, изменение и удаление карточек.
- Учёт закупочных и продажных цен, статуса «В наличии» / «Продан».
- Статистика склада, вложений, ожидаемой и реализованной валовой прибыли.
- Калькулятор с ориентировочными поправками за память, АКБ, комплект и состояние.
- Рассрочка с настраиваемой наценкой (по умолчанию +25%).
- Поиск и экспорт CSV.
- Демо-товар: Samsung Galaxy A35 5G 8/128, закуп 50 000 ₸, продажа 89 000 ₸.

## Запуск

Установите Node.js 18+ и выполните:

```bash
npm install
npm run dev
```

Откройте URL из терминала, обычно http://localhost:5173.

Для сборки:

```bash
npm run build
npm run preview
```

Для деплоя на Render Static Site: Build Command `npm install && npm run build`, Publish Directory `dist`.

## Важные ограничения MVP

- Данные хранятся в `localStorage` браузера. Они не синхронизируются между устройствами и могут исчезнуть при очистке данных сайта. Регулярно экспортируйте CSV.
- Нет регистрации, PostgreSQL, общего доступа сотрудников и сервера. Для производственной CRM потребуется backend, авторизация, резервные копии.
- Нет автоматического парсинга OLX или получения рыночных цен. Калькулятор использует **ручную базовую цену** и условные поправки, которые не заменяют анализ рынка.
- Рассрочка — математический расчёт наценки, а не интеграция с банком. Условия и законность оформления проверяйте отдельно.
- Величины прибыли валовые, за вычетом расходов только в калькуляторе.
